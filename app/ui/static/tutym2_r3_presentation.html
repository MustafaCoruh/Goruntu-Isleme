R3 Demo Başlatıcıya Git

1. Açılışta Söyle

“Bu demo T.UTYM#2 için güvenli operatör dashboard prototipidir. Gerçek kamera görüntüsü, RTSP URL, kamera IP veya credential göstermiyoruz.”

2. R3 Başlatıcıyı Göster

tutym2_r3_demo_launcher.html sayfasında R3 DEMO HAZIR ve PASS kontrollerini göster.

3. Dashboard'u Aç

T.UTYM#2 Dashboard Aç bağlantısıyla dashboard'a geç. Üstte R3 Demo Modu banner'ını göster.

4. Dashboard'da Anlatılacaklar

  1. Genel Durum: Dashboard state üzerinden sistemin genel durumu gösterilir.
  2. 14 Masa Kartı: T.UTYM#2 için hedef masa sayısı 14'tür.
  3. Rapor Güvenliği: Safety alanı gerçek RTSP/IP/credential/görüntü olmadığını belirtir.
  4. Uyarılar/Kritikler: Operatör kritik varsa canlı karar vermemelidir.
  5. Kaynak Raporlar: Readiness, config, RTSP, table accuracy gibi güvenli JSON özetleri dashboard'a kaynak olur.

Sunumda Kesinlikle Söylenmeyecek/Gösterilmeyecekler

  • Gerçek RTSP URL.
  • Kamera IP adresi.
  • Kamera kullanıcı adı/parolası.
  • Gerçek T.UTYM#2 fotoğrafı veya videosu.
  • Katılımcı/yüz/kimlik bilgisi.
  • Tam lokal Windows path bilgisi.

Beklenen Sorulara Kısa Cevaplar

  • Bu canlı kamera mı? Hayır, R3 demo güvenli örnek dashboard state ile gösterilir.
  • Gerçek sahada çalışacak mı? R4 aşamasında gerçek saha raporlarıyla doğrulanacak.
  • Kaç masa destekleniyor? T.UTYM#2 ilk hedefi 14 masa, 1 sandalye/masa.
  • Yüz tanıma var mı? Bu aşamada yok; ileride ayrıca güvenlik/hukuk değerlendirmesi gerekir.
  • İnternet gerekiyor mu? Çalışma ortamı offline olacak şekilde planlanıyor.
  • Gizli veri sızar mı? Tasarım gereği repo ve dashboard güvenli özetlerle çalışacak şekilde kurgulandı.

R3 Kapanış Cümlesi

R3 demo, T.UTYM#2 için güvenli dashboard ve operatör iş akışının sunulabilir olduğunu gösterir. R4 saha kabulü için gerçek lokal config, model, RTSP/readiness raporları ve masa bazlı doğruluk raporu üretilecektir.
