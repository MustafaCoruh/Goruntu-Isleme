# FTMC Occupancy

FTMC Occupancy is an initial prototype repository for occupancy-related image processing experiments.

## Repository Setup

Recommended initial workflow:

```bash
git clone <repo-url>
cd ftmc-occupancy
git checkout -b feature/initial-prototype
```

## Branches

- `main`: stable default branch
- `feature/initial-prototype`: first development branch

## Local Development

Create and activate a Python virtual environment before installing dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
```

Generated model artifacts, temporary outputs, and local environments are intentionally excluded from version control.
