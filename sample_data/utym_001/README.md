# UTYM 001 Sample Data

This directory contains text-based, synthetic, anonymized first-prototype sample visuals for UTYM occupancy analysis. The samples are committed as SVG files so the repository and pull request remain free of binary image assets.

## Contents

- `images/empty_room.svg`: empty room/table layout.
- `images/partial_occupied.svg`: some tables occupied.
- `images/crowded.svg`: all tables occupied/crowded.
- `images/changed_lighting.svg`: partial occupancy under changed lighting.
- `videos/`: reserved for a future short 1-3 minute session recording.

## Privacy notes

These files are generated synthetic top-down mockups. They do not contain real people, faces, readable names, screens, documents, or camera metadata. Occupant face areas are still represented with black anonymization masks to document the intended privacy handling for real captures.

## Video note

A real `sample_session.mp4` should be added when a safe 1-3 minute UTYM recording is available and encoded with project-approved tooling. Until then, this prototype dataset intentionally includes only text-based synthetic frames.
